# PawLog 工程版 PRD（供 AI 编码上下文使用）

> 本文是《爪记 · 宠物健康记录 App PRD v1.0》的工程精简版，去掉市场分析与论证，只保留可直接落成代码的部分。完整版见飞书文档。阅读顺序：1–5 章必读，第 7 章按当前里程碑查阅。

## 1. 产品与范围

给猫狗主人的私人病历本：30 秒记一条，看病时一页纸说清楚。

**v1 范围**：建档、记录、时间线、提醒、体重与体况、就诊摘要导出、家庭共享、订阅。
**不做**：社区、UGC、AI 问诊/诊断、电商、保险、硬件、Android、Web、无限相册。

## 2. 技术约束（硬性）

- Xcode 工程，Swift 6，SwiftUI，最低 iOS 17.0。
- 持久化 SwiftData；同步 CloudKit；图表 Swift Charts；PDF 用 PDFKit / UIGraphicsPDFRenderer；通知 UserNotifications；小组件 WidgetKit；内购 StoreKit 2。
- **禁止任何第三方运行时依赖**，不新增 Package、不使用 CocoaPods。
- 除 PDF 渲染外禁止 UIKit。
- 分层：View → Service → Model。View 不写业务规则，不直接改数据。
- 用户可见文案一律 `String(localized:)`，中文不进代码常量；枚举 rawValue 用英文。
- 单文件 ≤ 300 行；每个 View 提供 `#Preview` 与示例数据。
- 日期用 `Date.FormatStyle`，禁止手写 DateFormatter 拼接。

**工程结构**

```text
PawLog/
├─ App/            PawLogApp.swift, RootTabView.swift
├─ Core/
│  ├─ Models/      Pet, Record, WeightEntry, Reminder, Attachment
│  ├─ Services/    RecordService, ReminderScheduler, SummaryPDFBuilder, SubscriptionStore
│  ├─ DesignSystem/Theme.swift, Components/
│  └─ Utils/
├─ Features/       Pet, Timeline, Record, Health, Reminder, Settings
├─ Widget/
└─ PawLogTests/
```

| archived | Bool | 归档后只读 |
| createdAt | Date | |

### Record
| 字段 | 类型 | 说明 |
|---|---|---|
| id | UUID | |
| pet | Pet | 关系 |
| type | RecordType | vaccine / deworming / medication / visit / symptom / weight / daily |
| occurredAt | Date | 精确到日，允许过去 5 年，禁止未来 |
| title | String | 列表主标题 |
| note | String? | ≤500 字 |

| createdBy | String? | 成员昵称；本人为 nil |
| createdAt / updatedAt | Date | |

### WeightEntry
`id, pet, weightKg (0.1 精度), bcs (Int?, 1–9), date, recordID`
独立表用于曲线查询；同日多次取最后一次。

### Reminder
`id, pet, kind (vaccine/deworming/medication/visit/custom), sourceRecordID?, dueAt, repeatRule (none/daily/weekly/monthly), enabled, lastDoneAt`

### Attachment
`id, recordID, kind (image/pdf), localPath, thumbnailData, createdAt`
图片长边压至 2048，列表用 300pt 缩略图；每条最多 9 图 + 1 PDF。

### Entitlement
`productID, status, expiresAt, trialUsed`

**级联规则**：删除宠物级联删除其 Record / WeightEntry / Reminder / Attachment。

## 5. 功能需求

### 5.1 建档与多宠（P0）
- 必填：名称、物种。其余可空，中途退出自动保存草稿。
- 免费 1 只，Pro 上限 20 只。
- 首页宠物切换条：头像 56、名字 13，选中 2pt 主色描边；长按拖动排序。
- 删除宠物需输入宠物名确认，提示"将同时删除 N 条记录"。

### 5.2 七类记录的字段

| 类型 | 必填 | 可选 |
|---|---|---|
| 疫苗 | 疫苗名、接种日期 | 医院、批号、下次日期、不良反应 |
| 驱虫 | 体内/体外/体内外、日期 | 药品、下次日期 |
| 用药 | 药名、剂量、频次 | 开始/结束日期、给药方式、备注 |
| 就诊 | 医院、日期 | 医生、主诉、诊断、处置、费用、复诊日期 |
| 症状 | 类型、严重度 1–3、日期 | 持续时间、照片、备注 |
| 体重 | 数值、日期 | 单位、体况评分 |
| 日常 | 日期 | 喂食量、饮水、排泄、运动、心情（快捷标签） |

**症状类型枚举**：vomit / diarrhea / cough / skin / energy / appetite / excretion。

### 5.3 记录与时间线（P0）
- 中央 + → 选类型 → 表单 → 保存，最多 3 次点击可保存。
- 智能默认：日期今天；医院、药品取上次值；支持"照抄上一条"。
- 保存后 Toast"已记录"，返回来源页。
- 时间线：日期倒序分组，组头"2026 年 11 月"；同日 >3 条折叠；卡片显示图标、标题、一行摘要、宠物名。
- 详情支持编辑全部字段；删除需 Action Sheet 二次确认。
- 筛选（P1）：按宠物/类型/时间范围；搜索备注与药品名。

### 5.4 提醒（P0）
- 来源：记录自动生成 + 手动新建。
- 默认提前量：疫苗 30/7/1 天；驱虫按 30 或 90 天周期；用药按频次；复诊前 1 天。
- 全部本地通知；权限在首次保存记录后请求；22:00–08:00 默认静默。
- 通知动作"已完成"直接写回对应记录，不打开 App。
- 逾期：标红置顶，每天最多 1 条汇总通知。
- 列表分四组：今天 / 本周 / 以后 / 已逾期。

### 5.5 体重与体况（P0）
- 精度 0.1kg，kg/lb 可切；0.2–120kg 之外二次确认。
- 曲线范围 7/30/90/365 天；有理想体重时显示 ±10% 目标带。
- BCS 1–9：三步问答（俯视腰线、侧视腹部、摸肋骨），每步 3 选项；每 30 天提醒复评。
- 预警：30 天变化 ≥5% 或连续 3 次同向 → 浅橘提示"变化较快，建议咨询兽医"。**禁止出现病名或诊断措辞**。
- 12 月龄内显示"N 月龄"，提示每周称重。

### 5.6 就诊摘要（P0）
- 入口：健康页；范围 30/90/180 天，默认 90。
- 内容：基本信息、过敏史、在用药物、近 3 次就诊、疫苗记录、体重曲线、症状时间线、主人备注；可逐项勾选。
- 输出：A4 PDF（1–2 页）+ 竖版长图（宽 1080）；文件名 `宠物名_就诊摘要_YYYYMMDD.pdf`。
- 离线生成，≤1.5 秒；失败提供"重试"与"仅导出文字版"。
- 页脚固定免责："本摘要由宠物主人自行记录，仅供就诊沟通参考，不构成诊断或治疗建议。"
- 不走服务器，系统分享面板；默认不含主人手机号。

### 5.7 家庭共享（P0，Pro）
- CloudKit 共享，最多 5 人；所有者可管理成员、删宠物、管订阅；成员可读写记录、不可删宠物。
- 每条记录可显示"由 XX 记录"。
- 首页顶部同步状态：同步中 / 已同步 / 同步失败（可重试）。
- 冲突策略：last-write-wins，保留 updatedAt。

### 5.8 数据与隐私（P0）
- 不要求手机号/微信/邮箱登录；无广告与第三方追踪 SDK。
- 支持删除单条、单宠、全部数据；全部删除需输入"删除"。
- 默认 iCloud 同步；关闭时提示换机风险。

### 5.9 订阅（P0）
- 免费：1 宠、3 条提醒、90 天历史、摘要预览带水印不可导出。
- Pro：20 宠、无限提醒、完整历史、无水印导出、家庭共享、数据导出。
- 国内 ¥18/月、¥98/年、¥198 永久；海外 $3.99/月、$29.99/年、$59.99 永久。
- 付费墙触发：添加第 2 只宠物、点击导出、查看 90 天前、邀请家人。
- StoreKit 2；必须展示自动续订说明、取消方式、条款与隐私链接、恢复购买。

### 5.10 国际化（P0 基建）
- 默认跟随系统，设置内可切 跟随系统/简体中文/English，立即生效不重启。
- 文案集中在 String Catalog，key 语义化（`record.type.vaccine.label`）。
- 用户输入内容不翻译。
- 摘要支持中/英两版模板（P1）；英文术语：Vaccination、Deworming、Medication、Vet Visit、Symptoms、Weight、Body Condition Score。

## 8. 关键流程

1. 启动 → 引导 → 建档 → 首页 → 中央 + → 体重 → 保存（≤3 次点击）。
2. 健康页 → 生成摘要 → 选 90 天 → 预览 → 生成 PDF → 系统分享。
3. 所有者开通 Pro → 邀请家人 → 成员记录 → 所有者首页显示"由 XX 记录"。
4. 疫苗保存 → 自动生成 30/7/1 天提醒 → 通知"已完成"写回记录并生成下次。

## 9. 验收（每个里程碑都要过）

- 新建宠物必填校验生效，退出重进内容保留。
- 7 类记录可增删改，补记可选过去 5 年。

- 疫苗保存生成 3 条提醒，通知可一键完成。

- 飞行模式可生成 PDF，中文无乱码，页脚免责存在。
- 两账号共享可同步，成员无法删宠物。
- 删除全部数据后本地与 iCloud 无残留。
- 深色模式全页面可用，Dynamic Type 200% 不截断。
- 系统切英文无中文残留（用户输入除外），切回中文数据不丢。
